# 调研索引

新任务放 `research/YYYY-MM-DD-主题/`，一份 report.md 可包含问题、结论、出处、访问日期与采纳状态；必要素材放任务 assets，下载与中间结果放 outputs/research/同名任务。不为普通报告预建原型或工具。规则见 [AGENTS.md](AGENTS.md)。

| 资料 | 状态与边界 |
| --- | --- |
| [Marathon 研究](../marathon-design-research/README.md) | 历史参考；保留原型、素材和工具，不作为当前页面规范 |
| [既有研究资料](../docs/research/) | 历史参考；按主题检索，不当作未完成需求 |
| 根 Qiso 报告 | 渠道探测证据；按日期与已测范围理解，现行约定引用原报告 |

任务报告用“待采纳 / 已采纳 / 未采纳”记录建议状态；用户采纳后链接对应设计/现行说明，采纳不代表开发或上线完成。后续新增任务在此加一行即可，不复制全文。
