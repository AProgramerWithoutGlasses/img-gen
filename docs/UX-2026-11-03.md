# 2026-11-03 体验优化与验证

本轮按审批清单拆成 10 个独立提交。

1. 按账号保存创作草稿。文本和模型参数保存在本浏览器 localStorage，图片保存在 IndexedDB；覆盖、复用和新建前保留一份可撤销快照。存储失败会提示，草稿不跨浏览器同步。
2. 记住原比例和 Gemini 清晰度；混选、编辑或不兼容组合使用既有默认配置，切回兼容组合恢复选择。表单直接说明限制并展示最终生效参数。
3. 失败详情展示处理建议、本站退款状态、任务 ID 和请求 ID；允许复制不含提示词、图片和完整上游响应的诊断摘要。未知 400 不推断具体根因。
4. 基础图、参考图均有历史图片选择器，支持搜索、分页和交换角色。参考图读取原文件，基础图沿用服务端图片 ID；不以缩略图作为编辑输入。
5. 服务配置和作品列表区分加载中、读取失败、空记录与未配置，连接恢复后自动更新显示。
6. 历史页区分“继续草稿”和“新建创作”；失败详情的回填操作改为“载入参数并修改”，真正重新提交的入口明确提示重新计费。
7. 大图查看器支持当前列表内翻图、左右方向键、缩放、100% 和鼠标拖动。编辑结果支持与基础图比较，手机上下排列。原图仍由用户点击加载，失败不自动重试。
8. 手机后台请求记录改为卡片，展示状态、耗时、积分和缩略图；提示词与时间可展开。桌面保留表格。
9. 积分流水可打开对应任务；详情分别显示提交时冻结、实际消耗、已退还。成功结算可用余额变动为 0 的原因直接说明，手机流水使用纵向排列。
10. 模式、比例、筛选和后台导航补齐选中语义与非颜色标记；增强键盘焦点，手机主要控件最小高度 44px。

## 本地验证

使用实际 `web/` 文件和隔离模拟 API，在浏览器中检查以下行为，不调用收费上游：

- 刷新恢复提示词、Gemini Pro 2K、双图文件；替换和新建后撤销恢复。
- GPT 16:9 → GPT/Gemini 混选默认 → 取消混选恢复 16:9。
- Flash 4K → Pro 默认 → Flash 恢复 4K，未扩展任何模型参数组合。
- 历史素材分别载入两个位置、交换后刷新、图片正常解码。
- 失败诊断、剪贴板摘要、缺失请求 ID 的任务编号回退。
- 模拟配置 API 503 后显示“读取失败”，恢复连接后恢复表单；初始化不再显示虚假的未配置状态。
- 大图 100%、方向键切换、基础图/结果比较、Esc 分层关闭。
- 模拟原图 503 后保留高清预览，提示手动重试，仍可切换图片。
- 手机请求卡片展开、积分流水到任务详情及返回；约 390px CSS 视口无横向页面溢出。
- 比例按钮 `aria-pressed` 与视觉选中一致，手机触控高度满足 44px。

执行 `go test ./...`、`go vet ./...`、`go build ./...`、所有前端 JS 语法检查及 `node --test tests/feedback.test.cjs`。新增 Node 测试覆盖未知 400、处理中断的计费不确定性、诊断摘要脱敏和积分结算说明。

本轮没有数据库结构或 SQL 变更；未设置 `TEST_MYSQL_DSN` 时，已有 MySQL 集成测试按原机制跳过。模拟 API 验证不代表真实 Qiso 成功率、画质或耗时验证。临时夹具和截图放在被忽略的 `outputs/ux-20261103/`。
