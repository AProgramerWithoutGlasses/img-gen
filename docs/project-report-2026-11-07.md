## 4. 当前功能与边界

| 功能 | 当前实现 | 明确边界 |
| --- | --- | --- |
| 登录与个人设置 | 服务端账号、同源会话、改密、主题和发送偏好 | 身份、余额、权限以服务端为准 |
| 对话生图 | 五个模型选项，最多 6 附件，每次 1–4 张输出 | 每张独立调用；失败和中断不自动重试 |
| 附件编辑 | 按上传顺序传递；GPT 使用 `image/image[]`，Gemini 使用原生 `inlineData` | 使用默认编辑参数；六附件上游效果不因本地协议测试而视为已实测 |
| 我的图片 | 原比例图库、筛选、多选、单层文件夹、多归属 | 删除文件夹保留图片；没有新增图片删除业务 |
| 图片查看与复用 | 列表缩略图、高清预览、原图下载、结果添加为附件 | 不因整理工作改变原图和压缩预设 |
| 管理 | 用户、请求记录、模型按张定价、积分调整 | 在线充值服务尚未接入 |
| 旧接口 | `/api/jobs` 等兼容逻辑及相关后端测试保留 | 新界面未提供的旧功能不等于所有后端兼容代码都可删除 |

- GPT 三模型不展示质量和分辨率档位；比例仅是提示词引导，不能承诺固定输出尺寸。
- Flash 保留 0.5K/1K/2K/4K 和现有比例；Pro 名称存在映射到 Flash 的实测证据，不能以名称确认底层 Pro 能力。
- 当前保留 9 份 Qiso 报告、13 个 `probe_*` 脚本。它们包含历史实验边界，不应作为“旧测试”直接删除。
