# 前端接手说明

日期：2026-11-06。当前交付为 React + TypeScript + Vite 桌面前端，按现有 FigCraft 线框实现。所有业务操作使用本地模拟数据；未连接任何远程服务。

## 运行与代码入口

```sh
npm ci
npm run dev
# http://127.0.0.1:5174/
npm run verify:frontend
npm run build
```

构建输出 dist/。路由使用 hash，静态托管无需为每个子路由配置回退。检查使用 Playwright：Windows 使用已安装的 Edge；其他系统先执行 npx playwright install chromium。npm run verify 额外审计 FigCraft 工作稿，需要本项目的本地设计工具，后端接入方通常只需 verify:frontend。

| 位置 | 职责 |
| --- | --- |
| src/App.tsx | 主壳、导航、侧栏、全局预览、通知、未保存价格离开确认 |
| src/features/create/CreationPage.tsx | 提示词、模型条件参数、附件、发送和对话结果 |
| src/features/gallery/ | 原比例图库、多选、自定义文件夹、归类和移出 |
| src/features/settings/ | 个人设置、用户管理、请求记录、模型价格 |
| src/types.ts | 数据结构和 StudioActions 操作契约 |
| src/state/StudioContext.tsx | 目前的本地业务适配层；接入后端的主要替换点 |
| src/services/persistence.ts | IndexedDB 本地预览持久化 |
| src/config/models.ts | 五模型的当前参数配置，建议接入后改为服务端返回 |
| src/data/seed.ts | 可移除的示例账号、图片、价格和请求 |

## 接入方式

页面只通过 useStudio 读取 data/currentUser 并调用 actions。可保留其接口，把 StudioContext 中的本地变更替换为 HTTP 请求和查询缓存。成功响应后更新状态；失败抛出带可读 message 的 Error，表单已有错误入口。不要把 IndexedDB 中的用户角色、余额、价格或图片归属当作服务端事实。

建议接口分组如下，路径供双方约定，**当前没有实现这些 HTTP 端点**：

| 资源 | 需要的操作／返回内容 |
| --- | --- |
| 会话与账号 | 登录、退出、当前用户、修改密码；返回用户ID/用户名/角色/状态/余额/创建时间 |
| 模型 | 可用模型、档位、清晰度、比例、数量范围和默认值；稳定的模型ID |
| 附件 | 上传文件得到 attachmentId、预览URL、尺寸、文件名；不要直接传浏览器 data URL 作为生产协议 |
| 生成任务 | 提交提示词/附件ID/参数和幂等键，返回任务ID、冻结单价及状态；轮询或 SSE 更新完成/失败及结果图片 |
| 图片 | 分页查询本用户的成功图片；每张包含唯一ID、URL、尺寸、任务ID、输出序号、时间、提示词、参数和folderIds |
| 文件夹 | 列出、新建、重命名、删除；批量新增图片关联、移除当前文件夹关联 |
| 用户偏好 | 主题 light/dark/system、enterToSend；可继续浏览器本地保存或改为用户级持久化 |
| 管理员 | 用户分页/搜索/创建/更新/积分调整；请求筛选/详情/统计；模型单张价格读写 |

生产下载建议返回可下载URL或 Content-Disposition 响应；跨域URL不能假定 a[download] 一定生效。替换 src/lib/images.ts 的下载实现即可，不必改每个按钮。

## 保留的产品规则

- 不支持档位的模型隐藏控件；GPT Image 1.5 隐藏独立清晰度。切换模型时保留仍有效的值，重置无效值。模型能力来自第三方调研，不是已验证的服务端能力。
- 附件行在文字输入框外上方；有图显示，移除最后一张后整行消失。结果“添加”只加入下一轮附件，不自动提交。
- 生成成功图自动进入图库。当前预览以一批完成后统一入库、新批在前、同批按输出序号处理；准确的服务端入库时机仍需对齐。
- 图库已按用户要求去掉“有新图片·更新”和“最新生成在前”，不要恢复这两个控件。导航到图库直接读取当前数据。
- 一图可属于多个文件夹，归类不复制；全库每图只计一次。加入只新增关联；从文件夹移出只删除当前关联。无任何归属的图属于“未分类”。
- 删除文件夹保留所有图片及其他归属。没有图片删除或回收站接口／入口。
- 模型按张计费，非负整数，0免费。同模型生成和编辑同价；价格变更仅影响之后提交的任务。服务端负责余额并发校验、冻结价格与结算，前端只是预计值。
- 普通用户隐藏管理员入口且受路由保护；服务端仍须独立校验每个管理员接口和资源所有权。前端本地角色切换仅用于演示。

## 模拟边界与待对齐项

预览数据存放在同源 IndexedDB（ui-studio-preview-v1），包含本地上传的测试图片。示例结果是 SVG 线框占位图，发送不会调用模型。示例价格与余额不代表真实定价；生成约1.3秒完成仅用于显示等待状态。刷新中断的模拟任务会在下次启动标为失败并恢复本地占用积分，这不是生产退款策略。当前本地适配面向单个预览标签，不承担多端同步。

登录页为 `#/login`，包含用户名、密码、显示／隐藏、错误和提交状态。`actions.signIn(username, password)` 返回 Promise，成功后进入原目标页；直接访问登录页则进入创作。首次预览未登录，固定演示账号 `admin` / `user1`、演示密码 `preview1234`。口令仅是公开的本地测试常量，`src/services/previewAuth.ts` 不是真实认证；接入时替换为服务端登录和会话查询。用户输入的密码不会写入 IndexedDB。

新建用户只用于管理列表演示，不保存密码，也不能用初始密码登录本地预览。个人改密明确提示未接入，充值入口也仅提示未接入。生产接入移除 previewAuth 和 seed 数据；身份及权限只信任服务端，普通用户进入管理员路由仍须拒绝。

以下是前端可运行所用的暂定规则，接入时集中替换：

- 上传 PNG/JPG/WebP/GIF，最多6张、单张20MB；尚未与实际模型或后端限制确认。
- 文件夹单层，名称1–60字符，去首尾空格且同用户内不重名。
- 用户名按ASCII的字母/数字/下划线起始，后续允许点和连字符，总长3–32；密码以UTF-8计4–128字节。
- 本地用户管理提供角色/状态修改、整数积分增减且余额不能为负；不允许停用或降低当前管理员权限。生产审计、会话失效范围和积分调整规则由后端落实。
- 请求记录使用浏览器本地时区筛选，存储时间为ISO UTC；记录范围目前只有“全部记录”。生产列表需服务端分页和同条件统计。

本轮浏览器检查覆盖本地交互与刷新持久化，不验证真实鉴权、生图、收费、改密、充值或远程文件上传。
