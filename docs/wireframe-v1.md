## 页面与组件组织

画框内分为 `01 侧栏 / 展开`、`02 页头`、`03 对话工作区 / 第1轮`、`04 底部输入区 / 下一轮待发送`、`05 附件行 / 有图显示` 五个区域。附件行与文字输入框是同级容器，属于同一条待发送消息。结果组与附件列表使用横向自动布局，其余区域按固定桌面画面定位。

| 主组件 | 节点 | 复用和可编辑内容 |
| --- | --- | --- |
| 侧栏 / 导航项 | 618 | 名称文本、选中指示；“我的图片”为未选中实例 |
| 结果 / 图片卡片 | 653 | 图片标题、结果编号；第二张结果为实例 |

共 110 个内容节点，7 个主组件、6 个实例。文本、边框、图标、图片占位线均为原生可编辑对象；整页未栅格化。组件主件直接位于代表画面内，不额外建立大型规范板。编辑主件会同步实例；只改一项时使用实例文本属性覆盖。

10 条本地画布评论标注：演示数据、消息与结果归属、待发送附件归属、模型条件、用户菜单范围、图库后续范围，以及侧栏折叠、常驻上传入口、外置附件行和长提示词展开规则。组件条件也保存在节点 `pluginData.designNotes` 中。

## 当前确认的反馈调整

- 侧栏由 224 px 加宽到 280 px，导航项、积分区域和账户行随之加宽；顶部增加收起入口。收起状态按 72 px 图标栏标注，并保留顶部展开入口。当前只绘制展开状态，不制作可操作交互。
- 上传入口移到工具栏最左侧，使用常驻“＋”；无附件与有附件时都保留相同位置。上方附件区只展示文件卡片，不再保留虚线“添加图片”块。
- 附件行在文字输入框外、上方额外显示，不占用输入文字的位置。添加图片后显示附件行；点击图片右上角“×”逐个移除，删完最后一张后整行消失。附件行高 58 px，没有手动收起，也没有“参考图片 · 2”标题。文字输入框的位置与高度始终不变。
- 底部模型及参数选择器不显示“模型／档位／比例／清晰度／数量”等小字标签，只展示当前模型或参数值；按钮尺寸保持不变，值文字放大至 16 px 并在按钮内垂直居中，“发送”文字也为 16 px。控件名称和模型显示条件保留在图层命名与设计标注中。
- 默认文字区从 100 px 缩到 48 px，输入框总高从 202 px 缩到 144 px。右上角增加展开入口，长提示词使用更大的编辑区域；附件与工具栏规则不变。尺寸是结合 ArtCraft 紧凑输入布局后作出的设计取值，不将参考站尺寸直接当作本项目要求。
- “生成结果”标题右侧不再显示“已完成 · 2 张”，避免重复图片已经表达的完成状态和数量。
- 工具栏依次为上传＋、模型、档位、比例、清晰度、数量、预计积分、发送。主区水平余白由侧栏扩宽吸收，仍保持 1440 × 900；两张结果预览调整为 352 × 264，以容纳额外附件行并保留完整文字输入区域。

- [网站调研](research/website-research.md)：四站正式布局观察与交互检查均核验实际视口为 1440 × 900；早期窄屏入口检查不用于设计。
- [参数表](research/model-parameters.md) 与 [Gemini 别名](research/model-aliases.md)：五模型配置来源、官方别名及证据边界。
- [成熟组件模式](research/component-patterns.md)：Sender、Attachments、Image.PreviewGroup，仅采用结构和状态组织，没有确定代码组件库。
- v1.3 已运行 `npm run design:verify`：1 页、1 张 1440 × 900 顶层画面、110 内容节点，无缺失字体与审计警告。
- 附件布局验收 4 项通过、0 失败：[本地验证结果](../outputs/attachment-layout-check.json)。核对独立同级容器且无重叠、有/无附件时输入框渲染完全一致、错误的内部附件布局能被负向对照检测、实时与磁盘导出一致。[无附件对照截图](../outputs/attachments-empty.png) 用于与主稿比较文字区。对照在一次性无界面副本中执行，未改变工作稿。这验证静态布局关系；“点击×移除、删光隐藏”是已记录的显示条件，尚未实现可操作点击逻辑。
- 独立视觉检查和最终实时截图检查未发现截断、重叠或越界。实时画布 PNG 与本轮磁盘导出 PNG 的 SHA-256 完全相同，确认显示内容一致。该检查不等于交互测试；本阶段没有可操作页面。
- `npm run design:snapshot -- 611` 的路径查找未识别已打开文档。复核桌面 `doc.list` 与 `inspect_document` 后，使用同一附加 MCP 的文档 ID 5 调用 `screenshot`，将真实实时画布保存到上面的截图路径。没有拿旧磁盘导出替代实时画布，也没有修改连接脚本。

本轮只改设计与文档，未修改网页或自动化源代码，因此未运行网页构建与连接 smoke。审计、导出、实时截图均使用当前安装版 FigCraft。
