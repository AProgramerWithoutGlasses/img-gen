## 仍待产品确认的事项

这些事项不阻止当前静态线框交付，但不能在开发时当作既定规则。

- **提交条件与容量**：只有附件、没有提示词时是否允许发送；上传数量、大小及格式限制；重复添加同一结果图的处理。
- **模型切换与积分**：参数默认值、切换后无效值的重置规则、真实参数组合约束、预计积分及不足判定。线框只采用已调研菜单，积分为示例。
- **长文本返回**：关闭 ×、点击遮罩或其他返回方式是否保留尚未确认的修改。原站只验证了 Done 保留文字和 × 返回，未覆盖全部编辑情形。
- **处理中与失败**：是否可并行提交、继续输入、取消任务，重试入口的范围与费用处理。2023 和 1676 中的相应内容都是建议，不包含退款或耗时承诺。
- **图库查看增强**：大图查看层及生成信息面板、前后切换的集合范围，是否采用；是否把创作结果卡的下载／添加入口延伸到图库，以及其他图库管理需求，仍需另行确认。当前图库没有删除、批量或收藏功能。
