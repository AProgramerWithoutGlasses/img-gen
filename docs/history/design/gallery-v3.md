## 新图放入逻辑（设计建议，待审）

1. 一次生成结束后，成功图片一起进入“全部图片”和“未分类”。生成中／失败留在创作对话；上传参考图不进入生成图库。
2. 新入库的一组在前，同组按输出编号相邻。图片按原比例排成行；更新重新分行，旧图之间的先后顺序保持。
3. 浏览时显示“有新图片 · 更新”，原位置保持；点击更新回顶部，重新进入图库直接显示最新。新图不会因为正在浏览某文件夹就自动加入它。
4. 文件夹沿用全库顺序，归类不改变生成时间。图库可能比创作页稍晚出现同批全部成功结果，这是整批归组方案的取舍。

这些精确排序／刷新规则是本项目建议。ArtCraft、Krea 已实测文件夹操作；Adobe 官方文档支持生成历史自动保存，但本轮没有执行付费生成，不能把本项目排序写成原站事实。

## 已确认的文件夹范围

- 一图可属于多个文件夹，归类不复制；在全部图片中只计一次。
- 可新建、重命名和删除文件夹；没有图片删除或回收站。
- 创作页“添加”仍是加入待发送附件；图库的整理入口明确写“加入文件夹”。

具体语义采用以下建议供审阅：

| 行为 | 规则 |
| --- | --- |
| 未分类 | 没有任何文件夹归属的图片 |
| 加入文件夹 | 可选择多个目标；仅新增关联。已全部加入的目标置灰；部分加入的目标可补齐 |
| 移出此文件夹 | 只移除当前关系，其他归属不变；最后一个归属移除后回到未分类 |
| 删除文件夹 | 删除容器及其关联，所有图片保留；确认框说明后果，不出现同时删图选项 |
| 新建／重命名 | 单层目录；名称不能为空，去除首尾空格，重名就地提示。建议按创建顺序排列，重命名不跳位 |
| 从归类面板新建 | 保留已选图片，创建后返回目标列表，新目标被勾选；点击“加入”后才建立图片关联 |
| 从空文件夹选图 | 打开全部图片的选择状态，确认后加入当前文件夹；取消不改变关系 |
| 预览 | 前后切换仅限进入时的集合与顺序；关闭返回原位置。展示多个文件夹归属，提供下载与加入文件夹 |
| 反馈与失败 | 成功更新相应数量并提示；移出可撤销。请求失败保留选择和输入、原归属不变，可重试；不提前显示成功 |

首版不引入多级目录、归类副本、生成前指定文件夹、收藏、搜索、共享或排序配置；这些并非已确认范围。

## 调研结论与边界

此前没有实测 AI 图库的归类逻辑；本轮补查 ArtCraft、Krea、ImageAT，并读取 Adobe Firefly、Leonardo 官方资料。Base 沿用同日已验证的桌面网格。

ArtCraft 验证了新建、重命名、单图加入和移出，Krea 额外验证了批量整理、一图同时属于两个文件夹且全库计数不增加。三个空测试文件夹经用户确认已清理，测试图片恢复原归属；没有删除图片。非空文件夹删除后果没有实测，保留图片语义有 ArtCraft 确认文案与 Leonardo 官方文档支持。

Adobe 的整理动作创建副本，本项目不采用；Leonardo 的生成前归类和嵌套也暂不采用。原始截图与页面快照在 outputs/research/gallery/，账号信息不写入正式报告。
