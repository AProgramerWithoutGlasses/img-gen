# 后端局部规则

共同约束见 [根 AGENTS.md](../AGENTS.md)，运行与模块入口见 [studio/README.md](studio/README.md)。

- Go/MySQL 单实例队列；保留队列锁、冻结/成功结算/失败退款与旧 `/api/jobs` 兼容。结构迁移不改变数据库内容或 HTTP 协议。
- 每图单独调用上游，失败、中断不自动重试。最多六附件按前端提交的有序列表存储与转发，GPT 使用 image/image[]，Gemini 使用原生 generateContent/inlineData。
- 控件参数和渠道边界以 [接口契约](../docs/api-contract.md) 及其 2026-11-05 证据为准；转发参数不等于渠道兑现，不因本地 mock 通过宣称真实渠道通过。
- 保留原图、输入预处理、缩略图与预览的压缩策略和版本缓存语义。前端“基础图”仅标识当前编辑目标并置于附件首位，服务端仍接收有序 attachmentIds，不新增基础图／参考图角色字段或上游能力承诺。
- 增量迁移可重复运行，旧用户、任务、图片与积分保持兼容。密钥不进入浏览器；不打印或提交完整上游响应。
- 测试在仓库 tests 下，通过内部包接口测试真实实现；不复制业务逻辑、不在源码目录遗留测试桥接。数据库、race、构建等检查见 [测试说明](../tests/README.md)。
