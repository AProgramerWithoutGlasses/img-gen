# 前端局部规则

共同约束见 [根 AGENTS.md](../AGENTS.md)，这里仅补前端要求。

- 当前源码为 `frontend/src/`；页面导航和样式入口见 [README](README.md)。保留现有页面、交互与权限状态，不从旧根 src 或历史原型恢复产品实现。
- 外观或文案修改先更新并保存指定 FigCraft 稿，再同步实现；纯源码重构保持 DOM、样式、CSSOM/CSP 和交互一致。
- 页面专属组件跟随 features；共享组件不反向导入页面。应用组合放 app；真实请求在 services/state；模拟预览仅在 preview 模式加载。
- 服务端是身份、价格、余额和图片归属的权威；不能用模拟数据掩盖请求失败，不自动重试写请求。控件、六附件顺序及模型范围按 [接口契约](../docs/api-contract.md)。
- 浏览器测试、设计对照与样本独立存放；相关验证范围见 [测试说明](../tests/README.md)。保留原 7 条模拟流程，真实 Go/CSP 联调不能用模拟结果替代。
