## 当前主界面约定

- 工作区已完成图片支持勾选多选：顶部工具条显示数量、全选、单图继续修图、批量加入文件夹及取消。选中至少两张时禁用继续修图并显示原因；选择态点击图片切换选择，新批次、离页或Esc清除。复用现有批量文件夹接口，不增加生成调用。标题省去完成数和更多图标，提示词正文可打开全文；卡片菜单不重复提供查看大图。
- 生成张数初始1，按账号在当前浏览器记忆1–4张选择；刷新、切换模型或附件、重编辑历史均保留当前选择。反馈提示在顶部居中，普通3秒、带操作6秒关闭；按钮悬停提示与整组工具栏留出空隙，底部不足时翻到上方。

- 侧栏与主区域贴边，用细线分隔；桌面侧栏展开224px、收起72px，品牌为AiCraft。创作和图库不设独立全局顶栏；设置页保留标题栏。“我的图片”下直接提供全部图片、文件夹管理及可展开的单层文件夹列表，文件夹行右侧加号新建文件夹，主文件夹使用双层图标，账户行右侧显示积分，不增加未分类入口。窄屏以58px导航栏配合抽屉保持全部入口可达。
- 工作区只显示最新接收批次，历史成功图继续留在图库。提示词与状态在结果上方；1–4张图同批槽位同尺寸、末行居中。生成前按请求比例或首附件比例预留画框，未知自动比例使用16:9中性画框；本轮图片返回不改变比例或换列，成图完整适配并在必要时留边。历史结果可按已知图片比例优化；视口和输入增高仍正常响应。
- 每张图提供“继续修图／加入文件夹／下载”，移入图片或键盘聚焦时显示图内操作，移出后隐藏；触屏保留可达入口。近全屏大图使用 Yet Another React Lightbox 的 Inline 与 Zoom，提供缩略切换、缩放、平移、100%与可切换详情；正常查看按尺寸与DPR选压缩资源，点击“显示原图”、主动放大细节或选择100%时按需载入原图，统一显示加载中／已加载／手动重试状态；仅显示原图不改变缩放。衍生资源失败仍沿用原有权限检查和原图回退策略。
- “继续修图”返回创作并把该图放在附件首位，标为基础图；保留提示词草稿和其他参考图，替换先前基础图。六附件已满时提示处理，不静默丢弃参考图。这是前端编辑目标标识，请求仍只有有序附件，不新增服务端或上游角色字段。
- 亮暗主题使用单一高级蓝强调色（亮色`#315cbb`、暗色`#9ab9ff`）和中性灰度，红色表示警告或删除。亮色控件用更清晰的中性底、边界和蓝色箭头，禁用生成保持独立灰度。账户菜单宽度224px，与展开侧栏左右对齐；折叠与窄屏保留可达布局。积分与通用图标由Lucide React统一提供；已定稿对话框的加号与胶囊轮廓保留专用绘制。
- 每张图按服务端真实排队、生成、成功、失败状态独立显示；生成中使用活动条和实际开始后的运行秒数，上游没有百分比时不推算数字。图片解码后条收满并显示100%，先保留260ms的blur24／半透明预览，再用1100ms渐显清晰；清晰后进度与蒙层260ms一起退出，再启用图内操作。单图失败即时停止，成功图片保留，不自动重试；历史结果和减少动态效果直接清晰。
- 对话框可用宽度不超过760px时，配置工具栏按内容换行，保持按钮尺寸，确保窄屏下生成按钮可达。

本轮新增依赖的许可声明见 [第三方声明](../docs/third-party-notices.md)。

侧栏与创作布局以[侧边栏调整稿](../design/侧边栏调整小样.figcraft)第05页及动效分镜、第07页多选与反馈增量为准，图库与大图主体沿用主界面稿；亮暗控件、原图按钮及等宽账户菜单以调整稿第05页1812／1816／1835／1857为准。创作对话框延续独立稿的控件几何：容器随结果区同宽延展、默认高148px，正文16px/24px、顶边14px，输入按实际折行在两至八行间向上增长；配色与放置位置同步当前主界面稿。工具栏菜单、提示、最多六张附件及自适应悬停预览使用局部组件与样式。模型选择采用普通按钮填色，模型按钮166px，展开菜单最小166px并随文字自然伸展，左对齐且保留视口8px，菜单预留选中点；生成按钮使用当前主题强调色。附件栏随四至六张增宽；浮窗按图片包裹并显示在当前卡片正上方，图片资源按实际尺寸与DPR选择，见 [图片预览策略](../docs/image-preview-strategy.md)。显示简称仅在该工具栏与菜单映射，模型ID、请求和计费协议不变。原稿及其副本保留参考；旧主稿的整页映射不用于宣称本次对话框已对齐。早期设计依据见[行动报告](../research/2026-11-09-endfield-dialog/action-plan.md)，现行尺寸以当前指定稿和上述说明为准。

## 样式与数据

styles/tokens.css 管理亮暗主题变量，styles/base.css 为基础样式、components.css 为公共控件；app/layout.css 为布局，create.css、login.css、gallery.css、image-preview.css 与 settings.css 跟随功能。index.css 保持既有加载顺序，responsive.css 保留末尾响应式覆盖。共享组件放 components，页面局部组件跟随 features，app 负责组合。

真实数据请求由 services/api.ts 与 state/StudioContext.tsx 负责；服务端决定身份、余额、价格和图片归属，浏览器按用户存主题/发送偏好。preview/ 的 Provider、模拟认证、样例和 IndexedDB 仅模拟模式加载，不进入正式业务构建。

## 本地入口

从仓库根运行 `npm run dev`，5174 代理本地 Go 8080，Go 另行启动；`npm run dev:preview` 不需要后端，用固定示例看界面，不能代表真实保存或生成已通过。`npm run build` 构建并同步嵌入资源。

检查命令、7 条模拟流程、真实 Go/CSP 联调和截图路径统一见 [测试说明](../tests/README.md)。历史 [BACKEND_HANDOFF.md](BACKEND_HANDOFF.md) 只保留当时事实。
