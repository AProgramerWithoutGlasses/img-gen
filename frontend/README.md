## 当前主界面约定

- 创作工作区采用细密G软纹，法向周期5.29238px，颜色围绕当前主题底色变化，不整片提亮背景。纹理左右铺满，单个全页图层仅保留顶部105px向下、底部245px向上的平滑渐隐，底部75%力度合入mask；矮工作区分别缩至30%／70%，避免节点倒序。纹理位于内容下层且不接收点击，不延伸到侧栏、图库或设置。当前依据为默认设计稿第11页25539／25862，截图与输入框示意不改变现有组件。

- 图库和文件夹每批50张，接近底部续载，失败保留已加载内容并支持重试；标题与文件夹卡片使用服务端完整总数。预览延续相同分页集合，左侧缩略图只渲染可见项与缓冲项，支持桌面纵滚、手机横滚及Home／End切换已加载集合首尾。日常轮询只读最近10个完整批次与活跃任务，请求／积分历史按需读取；请求页点击查询会更新历史。
- 工作区已完成图片支持勾选多选：顶部工具条显示数量、全选、1–4图继续修图、批量加入文件夹、下载及叉号退出。窄屏工具条随内容排列，保持图片完整可见。选中超过4张时禁用继续修图，原因仅保留标题与无障碍说明；选择态点击图片切换选择，新批次、离页或Esc清除。复用现有批量文件夹接口，不增加生成调用。标题省去完成数和更多图标，提示词正文可打开全文；卡片菜单不重复提供查看大图。
- 生成张数初始1，按账号在当前浏览器记忆1–4张选择；刷新、切换模型或附件、重编辑历史均保留当前选择。反馈提示在主工作区顶部居中（排除侧栏，模态内按窗口居中），普通3秒、带操作6秒关闭；基础图成功提示单独为2秒且不显示关闭叉号；按钮悬停提示与整组工具栏留出空隙，底部不足时翻到上方。

- 侧栏与主区域贴边，用细线分隔；桌面侧栏展开224px、收起72px，品牌为AiCraft。创作、图库与设置均不设独立全局顶栏；六个设置页只保留内容标题，使用全宽滚动区包裹居中内容，滚动条贴工作区右缘，卡片、筛选和表格使用紧凑间距。“我的图片”下直接提供全部图片、文件夹管理及可展开的单层文件夹列表，文件夹行右侧加号新建文件夹，整行统一悬停底色，展开与新建均为28px控件／16px图标，仅自身悬停或键盘聚焦时加小底色；主文件夹使用双层图标，折叠后保留全部子文件夹图标入口、键盘与选中态，展开后沿用原列表开关。整个侧栏不显示悬停文字提示（导航、文件夹、新建、折叠及账户区域），保留悬停底色和无障碍名称。账户行右侧以16px Lucide Coins配合余额，亮暗均保留；不增加未分类入口。窄屏以58px导航栏配合抽屉保持全部入口可达。
- 工作区只显示最新接收批次，历史成功图继续留在图库。提示词与状态在结果上方；1–4张图同批槽位同尺寸、末行居中。生成前按请求比例或首附件比例预留画框，未知自动比例使用16:9中性画框；本轮图片返回不改变比例或换列，成图完整适配并在必要时留边。历史结果可按已知图片比例优化；视口和输入增高仍正常响应。
- 每张图提供“继续修图／加入文件夹／下载”，移入图片或键盘聚焦时显示图内操作，移出后隐藏；触屏保留可达入口。近全屏大图使用 Yet Another React Lightbox 的 Inline 与 Zoom，提供缩略切换、缩放、平移、100%与可切换详情；缩略轨道隐藏滚动条，桌面仅竖向、手机仅横向滚动，长列表首尾可达。正常查看按尺寸与DPR选压缩资源，点击“显示原图”、主动放大细节或选择100%时按需载入原图，统一显示加载中／已加载／手动重试状态；仅显示原图不改变缩放。衍生资源失败仍沿用原有权限检查和原图回退策略。
- “继续修图”支持逐张追加或多选1–4张，基础图最多4张，按添加顺序排在附件前部并逐张标记；保留提示词草稿、已有基础图和其他参考图的相对顺序。重复图片不增加数量，基础图超4张或总附件超6张时拒绝新增并提示，不覆盖或丢弃已有内容；删除、提交成功及恢复历史时同步清理相应基础图标记。这是前端编辑目标标识，请求仍只有有序附件，不新增服务端或上游角色字段。
- 亮暗主题使用单一高级蓝强调色（亮色`#315cbb`、暗色`#9ab9ff`）和中性灰度，红色表示警告或删除。亮色控件用更清晰的中性底、边界和蓝色箭头，禁用生成保持独立灰度。账户菜单宽度224px，与展开侧栏左右对齐；折叠与窄屏保留可达布局。积分与通用图标由Lucide React统一提供；已定稿对话框的加号与胶囊轮廓保留专用绘制。
- 每张图按服务端真实排队、生成、成功、失败状态独立显示；生成中使用活动条和实际开始后的运行秒数，上游没有百分比时不推算生成数字。图片解码后先保留320ms的blur24／半透明预览，再用1700ms渐显清晰；呈现百分比与白条沿同一时钟从0推进，画面清晰时才到100%，随后蒙层260ms退出，再启用图内操作。呈现百分比仅表示解码后的显示阶段。单图失败即时停止，成功图片保留，不自动重试；历史结果和减少动态效果直接清晰。
- 对话框可用宽度不超过760px时，配置工具栏按内容换行，保持按钮尺寸，确保窄屏下生成按钮可达。

本轮新增依赖的许可声明见 [第三方声明](../docs/third-party-notices.md)。

侧栏与创作布局以[侧边栏调整稿](../design/侧边栏调整小样.figcraft)第05页及动效分镜、第07页多选与反馈增量为准，图库与大图主体沿用主界面稿；亮暗控件、原图按钮及等宽账户菜单以调整稿第05页1812／1816／1835／1857为准。创作对话框延续独立稿的控件几何：容器随结果区同宽延展、默认高148px，正文16px/24px、顶边14px，输入按实际折行在两至八行间向上增长；配色与放置位置同步当前主界面稿。工具栏菜单、提示、最多六张附件及自适应悬停预览使用局部组件与样式。模型选择采用普通按钮填色，模型按钮166px，展开菜单最小166px并随文字自然伸展，左对齐且保留视口8px，菜单预留选中点；生成按钮使用当前主题强调色。附件栏随四至六张增宽；浮窗按图片包裹并显示在当前卡片正上方，图片资源按实际尺寸与DPR选择，见 [图片预览策略](../docs/image-preview-strategy.md)。显示简称仅在该工具栏与菜单映射，模型ID、请求和计费协议不变。原稿及其副本保留参考；旧主稿的整页映射不用于宣称本次对话框已对齐。早期设计依据见[行动报告](../research/2026-11-09-endfield-dialog/action-plan.md)，现行尺寸以当前指定稿和上述说明为准。

登录页与侧栏共用 ImagePlus 品牌图形及 AiCraft 名称。登录页提供公开注册：新账号为启用的普通用户、初始0积分；注册密码8–128 UTF-8字节，既有登录／改密维持4–128字节兼容，原生输入上限128字符后再校验字节长度，密码显隐使用Lucide。注册失败不自动重试；注册已成功而登录失败时提示直接登录。

图库和工作台共用 `ImageCardActions`、`ImageSelectionControl`、`ImageSelectionToolbar`，图内悬停／键盘聚焦提供修图、加入文件夹、下载及移入回收站，小卡把修图等操作收进更多菜单，删除仍可直接操作。点图仍查看大图，菜单不重复此入口。顶部多选条提供数量、未选满时全选、动作和叉号退出，不再重复显示取消全选；图库仅全选已加载图片，有后续页时明确标记范围。两处批量下载共用原图ZIP打包，每批最多500张／256MiB，串行鉴权读取、去除文件路径及重名、全部成功后保存一个包；失败明确提示，不下载半成品，不自动重试。fflate按需加载，图片不重复压缩。工作台提示词正文18px／26px。

回收站位于全部图片下方，支持单张与多选复原、彻底删除。回收站卡片悬停只显示选择框、复原与彻底删除，预览不提供修图／文件夹／下载；永久删除需确认。普通移入回收站可撤销，复原恢复仍存在的原文件夹关联。历史已生成数依据成功任务，积分消耗与余额均不因删除图片改变。数据层在删除成功后取消旧读取并更新缓存，防止旧响应重新显示图片。

## 样式与数据

styles/tokens.css 管理亮暗主题变量，styles/base.css 为基础样式、components.css 为公共控件；app/layout.css 为布局，create.css、login.css、gallery.css、image-preview.css 与 settings.css 跟随功能。index.css 保持既有加载顺序，responsive.css 保留末尾响应式覆盖。共享组件放 components，页面局部组件跟随 features，app 负责组合。

真实数据请求由 services/api.ts 与 state/StudioContext.tsx 负责；服务端决定身份、余额、价格和图片归属，浏览器按用户存主题/发送偏好。preview/ 的 Provider、模拟认证、样例和 IndexedDB 仅模拟模式加载，不进入正式业务构建。

## 本地入口

从仓库根运行 `npm run dev`，5174 代理本地 Go 8080，Go 另行启动；`npm run dev:preview` 不需要后端，用固定示例看界面，不能代表真实保存或生成已通过。`npm run build` 构建并同步嵌入资源。
